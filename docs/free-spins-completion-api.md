# Итоговое окно Free Spins: необходимое расширение API

Статус: frontend подготовлен под предложенный ниже контракт. В существующем коде и документации API подтверждён только CountFreeSpin (накопительный счётчик сыгранных FS). Общего серверного выигрыша сессии нет. Названия новых полей необходимо согласовать с API-разработчиком; это не описание уже работающего backend.

## Запрос API-разработчику

Расширить существующий POST /freespins объектом FreeSpinSession (либо согласовать эквивалентные SOAP-поля и их маппинг):

~~~json
{
  "CountFreeSpin": "130",
  "FreeSpinSession": {
    "id": "fs-session-unique-id",
    "status": "completed",
    "remaining": 0,
    "totalWin": "24.60",
    "currency": "USD",
    "creditedToBalance": true
  }
}
~~~

- id: стабильный уникальный строковый идентификатор всей серии. Дополнительные +15 FS сохраняют тот же id; новая серия получает новый id.
- status: active или completed. completed означает окончательное завершение с учётом дополнительных FS и всех результатов последнего спина.
- remaining: целое число оставшихся FS в этой серии, включая дополнительные. Это не CountFreeSpin.
- totalWin: окончательный общий выигрыш всех FS серии в основных единицах валюты, без выигрыша запускающего платного спина. Для 15 + 15 FS включает все 30. Ноль передаётся явно как "0.00". Предпочтителен десятичный текст с двумя знаками; frontend не складывает выигрыши для диалога.
- currency: трёхбуквенный код валюты суммы.
- creditedToBalance: boolean, подтверждающий зачисление всей суммы серии, включая выполненные ранее выплаты. Для завершённой нулевой серии также true после окончательного расчёта.

Сервер возвращает актуальную либо последнюю завершённую серию для игрока и игры, включая повторный вход. После успешного существующего /pay чтение /freespins должно видеть актуальный статус выплаты. Это расширение не вводит новый вызов выплаты и не меняет существующий платёжный порядок.

## Поведение frontend

Итог запрашивается после раскрытия последнего спина и успешной выплаты серии, а также при восстановлении завершённой серии. Диалог открывается только при completed, remaining=0, creditedToBalance=true и корректной сумме/валюте. Отсутствующий FreeSpinSession не заменяется локальной суммой, WinSum последнего спина или нулём. Некорректный ответ/ошибка сети передаётся существующему обработчику ошибок; повторный вход позволяет повторно запросить итог.

При показе останавливается autoplay. ПРОДОЛЖИТЬ закрывает диалог и разблокирует обычную игру без автоматического платного спина. Нулевой выигрыш тоже показывается. Показ сохраняется по игроку, игре и id серии в localStorage, чтобы повторный ответ или перезагрузка не открывали окно снова. Если хранилище недоступно, защита действует в рамках текущей страницы. Для гарантии между устройствами/после очистки хранилища необходим серверный признак подтверждения показа и соответствующий API.

До реализации расширения backend итоговое окно с суммой не может работать на реальных данных. Существующий счётчик и текущая механика FS остаются совместимыми с прежним ответом.
